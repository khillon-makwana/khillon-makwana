statement. Checks every running balance to find missing or misread rows. Kept all data on the user's device, enforced by a Content Security Policy and local storage, with 229 automated tests.

`TypeScript` `Next.js` `pdf.js` `IndexedDB` `Zod` `Vitest`

`NestJS` `Next.js` `PostgreSQL` `Redis` `Socket.IO` `M-Pesa Daraja API` `Jest`
